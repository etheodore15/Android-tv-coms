📱 Phone

Download phone app
  1. Open this page on the phone and tap the button above (or scan the QR code below from another screen).
  2. When asked, allow installing from your browser ("unknown sources").
  3. Open the downloaded file to install, then open the app: enter the link code shown on the TV screen (install the TV app first — it displays the code), set your name, allow notifications, accept the battery-optimisation exemption.

Viewing this on a computer? Scan the QR code with the phone's camera to download directly.

📺 TV

Easiest way — with the free Downloader app (Play Store on the TV):

  1. On the TV, install "Downloader by AFTVnews" from the Play Store.
  2. In the TV's settings, allow Downloader to install unknown apps (Settings → Apps → Security & restrictions → Unknown sources).
  3. Open Downloader and enter this address:
tv.apk

It downloads and offers to install. Afterwards, launch FamilyTV Link once from the TV launcher — it displays a link code to enter on each phone. Grant the overlay permission when prompted, then press "Test overlay".

Alternative — from a computer with adb:

adb connect <TV_IP>:5555 && adb install -r tv.apk

(Download tv.apk to the computer first. Enable network debugging in the TV's developer options.)

Once installed, the apps update themselves: they check this page and show an "Update" button on their settings screens — you rarely need to come back here.
